# Campo Harmônico — treino de memória musical

App interativo para estudar campos harmônicos e praticar a identificação das funções dos acordes. A aba **Família** associa cada grau a uma figura e a um papel harmônico, com cartões clicáveis que reproduzem o acorde correspondente.

## Recursos

- Mapa visual dos sete graus em diferentes tonalidades.
- Campos harmônicos maior e menor natural.
- Reprodução de acordes e sequências.
- Quiz de recuperação rápida.
- Aba **Família**, com Pai (I), Mãe (IV), Filho Rebelde (V) e cartões individuais para os graus II, III, VI e VII.
- Interface adaptável para celular e computador.

## Arquivos

- `index.html` — página de entrada do GitHub Pages.
- `campos-harmonicos.html` — aplicativo propriamente dito.

## Usar localmente

Baixe os dois arquivos na mesma pasta e abra `index.html` em um navegador moderno. Para ouvir os acordes, permita a reprodução de áudio e toque num cartão ou botão de reprodução.

## Observação musical

O app apresenta o campo maior e o menor natural. As associações familiares são um recurso mnemônico para ajudar a lembrar funções harmônicas; são analogias de estudo, não regras absolutas sobre como toda música funciona.
